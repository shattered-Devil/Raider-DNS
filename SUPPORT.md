# Support and troubleshooting

- Read the root README and the guides in `docs/`.
- Search existing GitHub Issues before opening a new one.
- For reproducible defects, use the Bug Report issue form and include Raider DNS version, Windows build, connection mode, exact steps, and sanitized error messages.
- Do not post credentials, private IP/host details, recovery snapshots, or full adapter dumps publicly.
- Security vulnerabilities should be reported privately according to `SECURITY.md`, not in a public issue.
- Network-changing tests and sing-box TUN recovery tests must be performed in a disposable, snapshot-backed Windows VM.
