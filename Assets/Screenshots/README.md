# Application screenshots

Place current, genuine Raider DNS screenshots in this folder after testing the final Windows build. Suggested captures:

- `dashboard.png` — Dashboard and resolver benchmark table.
- `connections.png` — Connection modes and provider selection.
- `diagnostics.png` — Diagnostics and manual repair screen.
- `settings.png` — Theme and application settings.

Before committing, redact public IP addresses, private hostnames, Windows account names, adapter/device identifiers, custom profile names, local paths, and any recovery data. Do not use the old troubleshooting screenshots that show the earlier DNS errors as promotional screenshots.
